# L'Hack Des Maths

Site officiel de **L'Hack Des Maths**.

## Structure

- `index.html` — page d'accueil
- `courses.html` — bibliothèque des cours
- `lesson.html` — modèle de page de chapitre
- `css/style.css` — design responsive
- `js/app.js` — navigation + animations
- `js/courses.js` — recherche et filtres
- `pdf/` — place tes fichiers PDF ici

## Couleurs de marque

- Violet : `#66229F`
- Jaune : `#FFD900`
- Blanc : `#FFFFFF`

Le site est mobile-first et compatible avec Cloudflare Pages.
